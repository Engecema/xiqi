# XIQI OS v1.0 — Corporação Engecema

Sistema Operacional corporativo ultraleve e independente, projetado para estações corporativas e mini data center Engecema.

## Recursos Principais

- **Núcleo Independente (XIQI OS Core x86_64)**: Ambiente gráfico otimizado com acesso direto à interface corporativa em tela cheia.
- **Espaço de Trabalho Web Multiabas**: Navegador dedicado XIQI OS com barra de endereço editável, histórico por aba e carregamento via Proxy XIQI.
- **Pesquisa Web & XIQI AI**: Motor de busca integrado e assistente inteligente XIQI AI.
- **Privacidade Local**: Bloco de notas pessoal armazenado exclusivamente no dispositivo local do usuário.
- **Painel Administrativo (/admin)**: Gestão de usuários corporativos protegida por Chave Mestra.
